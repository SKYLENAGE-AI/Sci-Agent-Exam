# Magnetized Laser-Plasma Harmonic Diagnostic

The workflow used the local SQLite catalog to enumerate accepted `harmonic_probe` candidates for a laser-plasma harmonic-generation diagnostic, then joined each candidate to the diagnostic contract that defines the signal group, time axis, spectral window, band widths, detrending, normalization, prominence, modulation, and phase conventions. The catalog run rows supplied the candidate-specific validation thresholds. The selected candidate is `magnetized_h3_probe` at harmonic order `3` because its windowed `Ey` spectrum has a validated peak, power ratio, prominence, and `Ey`/`Bz` phase relation, while the other accepted harmonic candidates fail at least one catalog validation rule.

The Smilei-style namelist was parsed with Python call-recording stubs for `Main`, `ExternalField`, `LaserPlanar1D`, `Species`, `DiagProbe`, and `DiagFields`. This recovered the laser fundamental frequency, laser amplitude, simulation cadence, probe and field lists, and the `Bz` field perpendicular to the x-propagating laser. The resulting magnetization parameter is `0.73338598`, so the harmonic interpretation is tied to a magnetized laser-plasma setup rather than an unmagnetized spectrum-only analysis.

The probe HDF5 structures for accepted candidates were inspected with `h5dump -n` before their probe arrays were loaded for candidate validation, and the selected probe tree was preserved as the probe handoff artifact. After selection, the selected field HDF5 structure was inspected with `h5dump -n` before loading electromagnetic energy for the separate late-time consistency diagnostic. The probe HDF5 contract supplied the signal group and dataset names used for `Ey`, `Bz`, and the charge channel `Rho`.

The signal stage used the contract analysis window and `blackmanharris` window function, detrended the selected trace according to the contract, and computed the real FFT in normalized angular-frequency units. Mean removal suppresses DC leakage into low-frequency bins, while the finite window sets the frequency resolution and confines the harmonic decision to contract-defined bands. The selected harmonic peak is at `2.99882858` times the laser frequency, with signed frequency error `-3.904725e-04`. Its band-power ratio to the fundamental is `0.01980480`, which quantifies harmonic-band conversion relative to the laser fundamental, and its peak prominence `6.871852e+14` guards against accepting noise-floor or leakage structure as a harmonic. The noise-floor audit records the off-harmonic median background used for that prominence calculation rather than treating the threshold as an isolated scalar.

The charge-channel handoff applies the same spectral window and power normalization to `Rho` and compares the `Rho` harmonic-band power with the selected `Ey` harmonic-band power. The selected charge-coupling ratio is `0.31739733`, which keeps the plasma-response evidence separate from the electromagnetic conversion and phase checks while still participating in candidate validation.

Polarization validation was performed from the complex FFT coefficients, not from a visual peak alone. The selected harmonic `Ey`/`Bz` phase lag is `-1.18000032` rad, with phase error `3.229507e-07` rad against the selected catalog rule. This supports the verdict `magnetized_harmonic_confirmed` when combined with the spectral power and frequency checks.

The intermediate artifacts expose the handoffs: catalog selection, candidate audit, namelist summary, HDF5 trees, windowed signal samples, harmonic spectrum rows, noise-floor audit rows, charge-coupling rows, polarization validation, electromagnetic energy, and harmonic validation metadata. The submitted `code/solve.py` honors the caller-provided output directory while reading `ORCHESTRATE_DATA_DIR` when set, so the same offline workflow can regenerate `answer.json`, intermediate handoffs, and the figure into a scratch results directory. The energy modulation index is interpreted only as a late-time consistency metric; it cannot replace the catalog frequency, power, prominence, charge-coupling, and phase checks that set the verdict. The figure `harmonic_spectrum.png` shows the computed spectrum with the fundamental and selected harmonic locations.

Limitations: this is an offline Smilei-style diagnostic bundle rather than a fresh PIC campaign. The conclusion depends on the mounted diagnostic cadence, the finite FFT window, the single probe boundary signal, and the catalog-defined validation thresholds; production follow-up would vary resolution, plasma density, pulse envelope, and magnetic-field strength.
